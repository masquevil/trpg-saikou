# scenario-writing

围绕作者想要的体验，把故事写成玩家能够调查、介入并改变结果的局面。

## 核心原则

1. **先对齐意图**：读创作原点、当前稿与参考材料，区分必须保留项和可改项。改进优先修补；尊重作者选择的悲剧与难度，按上下文区分游戏内后果与场外处罚。
2. **先因果，后玩法**：确定各方目标、能力边界、时间线和无人介入时的发展，再设计线索与场景。受害者状态、敌人行为须有故事内原因，玩法需求不能替代动机。
3. **让介入成立**：明确调查员为什么来、为什么留下、掌握什么独特信息。现代背景交代现实调查进展及限制，让求助和新证据真正推动行动，保留调查员凭信息与关系发挥的空间。
4. **人物有差异，事件有后果**：NPC 从处境与关系中行动，按重要性分配篇幅。秘密和创伤按需使用。重要事件写清发起者、触发条件、可参与行动及后续变化；预防和准备成功后，局势应实际改变。
5. **情感与危险遵循同一因果**：用相处和行动建立关系，让援助、牺牲、失去信任乃至团灭符合既定能力与风险。重要代价事先可知，自创解法依已有设定裁定，人物冲突仍需由人物选择解决。
6. **正文呈现当前事实**：直接整合到指定文件，只保留设定与必要主持指导。文件用途放结构说明，修改过程留在对话。判断一句话是否该留：不知道讨论历史的读者，是否需要它理解或使用模组？例如写“摄取被打断时仍可救人”，而非“没有留着活人等救援”。

## 交付检查

重读全文，核对因果、人物状态、线索与事件分支、终局及展示材料的一致性，清理废弃设定和辩解式否定。沿用项目解析语法，表格保持紧凑；分别说明纸面推演、数值验证与实际跑团的完成情况。
